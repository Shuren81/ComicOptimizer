📚 ComicOptimizer v2.1.5

La soluzione definitiva per la gestione, riparazione e ottimizzazione della tua libreria di fumetti digitali.

Sviluppato con passione da Michele "Shuren" Bancheri, ComicOptimizer nasce dall'esigenza di trasformare collezioni disordinate e pesanti in librerie fluide, standardizzate e pronte per qualsiasi lettore[cite: 1, 3].
🚀 Cosa c'è di nuovo nella v2.0+

La versione 2.0 segna un punto di svolta per il progetto[cite: 3]:

    Supporto PDF Nativo: Conversione fluida da PDF a CBZ con estrazione immagini ad alta fedeltà[cite: 1, 3].

    Motore Turbo: Gestione della memoria ottimizzata e velocità di elaborazione raddoppiata[cite: 3].

    Interfaccia Asincrona: Grazie a un sistema di threading avanzato, l'UI rimane reattiva anche durante la scansione di migliaia di file[cite: 1, 3].

    Gestione Conflitti: Sistema intelligente per decidere se sovrascrivere, rinominare o saltare file esistenti[cite: 1].

✨ Funzionalità Principali
🛠️ Standardizzazione Universale

    Conversione Totale: Importa .pdf, .cbr, .rar, .zip e trasformali istantaneamente nello standard .cbz[cite: 1, 3].

    Ottimizzazione WebP: Riduci drasticamente il peso della tua collezione senza sacrificare la qualità visiva[cite: 1, 3].

    Sanificazione Archivi: Eliminazione automatica di file "spazzatura" come .DS_Store, __MACOSX o file temporanei[cite: 1, 3].

🧠 Intelligenza e Controllo

    Analisi Duplicati: Algoritmo che confronta metadati e conteggio pagine per identificare doppioni inutili[cite: 1, 3].

    Advanced Editor: Un editor visuale integrato per riordinare pagine, eliminare scansioni errate o aggiungere nuove immagini a un archivio esistente[cite: 1, 3].

    Integrazione di Sistema: Gestione sicura degli scarti tramite gio trash, ottimizzata specificamente per Linux Mint[cite: 1, 3].

📦 Installazione e Requisiti
1. Dipendenze di Sistema (Linux/Ubuntu/Mint)

Per gestire gli archivi e i file PDF, apri il terminale e installa:
Bash

sudo apt update
sudo apt install p7zip-full unrar

2. Dipendenze Python

Installa le librerie necessarie tramite pip:
Bash

pip install PyQt6 Pillow pymupdf

🛠️ Utilizzo Rapido

    Avvio: Esegui lo script con python3 comic_optimizer.py[cite: 1].

    Importazione: Trascina i tuoi file o cartelle direttamente nella "Drop Zone" dell'app[cite: 1].

    Analisi: Clicca su "Analizza" per individuare file danneggiati o duplicati[cite: 1].

    Ottimizzazione: Scegli se riparare i file o convertirli in WebP per risparmiare spazio[cite: 1].

🛡️ Privacy e Sicurezza

    100% Locale: Nessun dato o immagine viene caricato su server esterni. Tutto avviene sul tuo PC[cite: 3].

    Resilienza: Gestione sicura dei processi: se interrompi un'operazione, i tuoi file originali rimangono intatti fino alla corretta creazione del nuovo archivio[cite: 1, 3].
